# skasim planning docs

This folder contains planning and product-definition documents for image-based model injection in `skasim`.

## Files
- `CONTEXT.md` — shared domain language and project vocabulary.
- `PRD.md` — product requirements for version 1.
- `MODEL_INPUT_CONTRACTS.md` — compact definition of accepted model-entry contracts.
- `VALIDATION_TEST_MATRIX.md` — recommended validation and regression matrix.
- `adr/ADR-0001-separate-model-entry-contracts-from-model-preparation.md`
- `adr/ADR-0002-use-casa-ft-as-the-default-v1-image-injection-backend.md`

## Intent
- `CONTEXT.md` is conceptual and non-implementation-specific.
- `PRD.md` is the main implementation-planning document.
- ADRs capture major architectural decisions that are worth preserving.
